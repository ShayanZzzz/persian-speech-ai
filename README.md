# Farsi Speech AI

An open-source project for working with Persian (Farsi) speech recognition and speech processing.

The main goal is to build a Persian speech AI system from the ground up, starting with Whisper and gradually working through the parts needed for a real-world system.

### What I'm working on

* Persian Automatic Speech Recognition (ASR)
* Audio preprocessing and segmentation
* Voice Activity Detection (VAD)
* Speech dataset preparation
* Evaluating models with Word Error Rate (WER)
* Fine-tuning Whisper for Persian
* Improving inference speed and latency

For now, most of the experiments are being done in Google Colab. The project will evolve as I learn and experiment with different approaches.

### Status

Early stage — currently focused on experiments, dataset preparation, and building the first working pipeline.
